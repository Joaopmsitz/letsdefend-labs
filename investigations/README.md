# 📁 Security Investigations

This directory contains security investigations performed during hands-on SOC Analyst training on the Let's Defend platform.

Each report documents the analysis of a security alert, including evidence collection, investigation methodology, threat validation, and final verdict.

---

## 📂 Categories

- 📁 malware/ → Malware-related investigations
- 📁 phishing/ → Phishing emails, malicious attachments, and URL-based attacks
- 📁 web-attacks/ → Web application attacks, SQL injection, and script injection attempts

---

## 🧠 Content Included

Each investigation may include:

- Alert details
- Investigation methodology
- Evidence analysis
- Network activity review
- Indicators of Compromise (IOCs)
- MITRE ATT&CK mapping
- Response actions
- Final verdict (True Positive / False Positive)

---

## 🎯 Skills Demonstrated

- Alert triage and investigation
- Threat validation
- Malware analysis
- Phishing analysis
- Log review and correlation
- IOC identification
- MITRE ATT&CK mapping
- Incident response workflows
