# 📁 Security Investigations

This directory contains security investigations performed during hands-on SOC Analyst training on the Let's Defend platform.

Each report documents the investigation of a security alert, including evidence collection, analysis methodology, threat validation, and final verdict.

---

## 📂 Categories

### 🦠 Malware
Investigations involving suspicious files, malware execution, payload delivery, and threat validation.

### 🎣 Phishing
Investigations related to phishing emails, malicious attachments, malicious URLs, and social engineering attempts.

### 🌐 Web Attacks
Investigations involving SQL injection attempts, JavaScript injection, and other web application attacks.

---

## 🧠 Investigation Methodology

Each investigation may include:

- Alert details
- Investigation process
- Evidence analysis
- Network activity review
- Indicators of Compromise (IOCs)
- MITRE ATT&CK mapping
- Response actions
- Final verdict

---

## ✅ Possible Outcomes

Investigations result in one of the following outcomes:

- **True Positive** — Malicious activity confirmed
- **False Positive** — Alert triggered without malicious activity
- **Benign Activity** — Legitimate activity incorrectly identified as suspicious
