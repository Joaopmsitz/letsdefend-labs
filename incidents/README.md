# 📁 Incident Reports Index

This directory contains all security incident investigations performed during my SOC training on the Let's Defend platform.

Each folder represents a categorized security incident with full analysis, including detection, investigation, evidence, and final conclusion.

---

## 📂 Structure

- 📁 malware/ → Malware-related incidents (file-based attacks, execution, payloads)
- 📁 phishing/ → Email-based attacks and social engineering cases
- 📁 web-attacks/ → Web exploitation attempts (SQLi, XSS, injection)

---

## 🧠 Content Included in Each Incident

Each incident folder may include:

- Detection details (alert and event information)  
- Log analysis and investigation steps  
- Network traffic analysis (if applicable)  
- Indicators of Compromise (IOCs)  
- MITRE ATT&CK mapping  
- Response actions (containment, analysis)  
- Final conclusion (True Positive / False Positive)
