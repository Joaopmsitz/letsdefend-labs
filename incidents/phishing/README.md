# 🟣 Phishing Incident Reports

This directory contains all phishing-related security incident investigations performed as part of my SOC training on the Let's Defend platform.

These incidents focus on identifying and analyzing malicious emails, social engineering techniques, and payload delivery through email-based attacks.

---

## 📂 Included Incidents

- SOC282 - Phishing Alert: Deceptive Email Detected

---

## 🎯 Attack Types Analyzed

This section covers different phishing techniques such as:

- Deceptive or spoofed email content  
- Malicious attachments (e.g., Excel macros, PDFs)  
- Credential harvesting attempts  
- Social engineering techniques  
- Email-based malware delivery  

---

## 🔍 SOC Investigation Focus

Each phishing incident includes analysis of:

- Email headers and sender reputation  
- Suspicious attachments or links  
- Payload behavior (if executed)  
- Indicators of compromise (IOCs)  
- User interaction analysis  
- Potential impact assessment  

---

## 🧠 SOC Workflow Applied

- Email alert triage  
- Header and metadata analysis  
- Link/attachment inspection  
- Threat validation (True Positive / False Positive)  
- Incident classification  
- Response recommendations  

---

## 🎯 Objective

To develop practical SOC Analyst skills in phishing detection, email security analysis, and social engineering threat investigation.
